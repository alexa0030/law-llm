# 数据集说明

## 数据来源

本项目使用以下公开数据集：

### 1. 法律 SFT 数据

| 数据集 | 说明 | 数量 |
|--------|------|------|
| DISC-Law-SFT | 复旦大学法律智能实验室发布的中国法律 SFT 数据集 | ~30K |
| JEC-QA | 司法考试题库，含刑法、民法等参考书籍 | ~10K |
| 自建法律咨询数据 | 基于真实法律咨询场景构建 | ~9K |

### 2. 通用指令数据

| 数据集 | 说明 | 数量 |
|--------|------|------|
| alpaca_gpt4_data_zh | 基于 GPT-4 生成的中文 Alpaca 数据 | ~50K |

### 3. 法律知识库（RAG）

| 文档 | 说明 |
|------|------|
| 中华人民共和国刑法 | 含历次修正案 |
| 中华人民共和国个人信息保护法 | 2021年8月20日通过 |
| 其他法律文档 | 持续扩充中 |

## 数据处理流程

```
原始数据
  ↓ 格式统一 (query/response → instruction/output)
  ↓ 规则清洗 (过滤娱乐、事实记忆、低质量、模板化内容)
  ↓ 精确去重 (MD5 哈希)
  ↓ 语义去重 (Sentence-BERT + FAISS, 阈值 0.80)
  ↓ 代表性采样 (K-Center-Greedy, 按能力分类配额)
  ↓ 混合 (法律:通用 = 8:2)
  ↓ 划分 (训练:验证:测试 = 8:1:1)
```

## 能力分类

通用数据按以下四个能力维度进行分类采样：

| 能力 | 配额 | 关键词示例 |
|------|------|-----------|
| 长文本理解 | 30% | 背景、事件、篇章、摘要、总结 |
| 逻辑推理 | 30% | 因为、所以、推理、因果、前提 |
| 结构化表达 | 20% | 首先、其次、综上所述、步骤 |
| 歧义消解 | 20% | 什么意思、澄清、定义、区分 |

## 数据格式

### SFT 训练数据 (Alpaca 格式)

```json
{
  "instruction": "什么是故意犯罪？",
  "input": "",
  "output": "明知自己的行为会发生危害社会的结果..."
}
```

### RAG 法条数据 (Markdown)

```markdown
# 中华人民共和国个人信息保护法

2021年8月20日 第十三届全国人民代表大会常务委员会第三十次会议通过

## 第一章 总则

第一条 为了保护个人信息权益，规范个人信息处理活动，促进个人信息合理利用，根据宪法，制定本法。
```

## 获取数据

由于数据集较大，不直接入库。请通过以下方式获取：

1. **DISC-Law-SFT**: [HuggingFace](https://huggingface.co/datasets/ShengbinYue/DISC-Law-SFT)
2. **JEC-QA**: [GitHub](https://github.com/JEC-QA/JEC-QA)
3. **alpaca_gpt4_data_zh**: [HuggingFace](https://huggingface.co/datasets/shibing624/alpaca-zh)

下载后放入 `data/raw/` 目录，然后运行：

```bash
make data
```

## 数据处理报告

每次运行 `prepare_data.py` 会生成处理报告，包含：

- 原始数据数量
- 格式错误数量
- 规则过滤数量（按原因分布）
- 语义重复数量
- 最终保留数量
- 训练/验证/测试划分数量
- 类别分布
- 随机种子
- 运行配置

报告保存在 `data/processed/processing_report.json`。
