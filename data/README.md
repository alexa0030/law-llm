# 数据目录

本目录存放法律文档、示例数据和评测数据。

## 目录结构

```
data/
├── laws/              # 法律法规文档（Markdown 格式，用于 RAG 建库）
│   ├── 刑法/
│   │   ├── 刑法.md
│   │   └── 刑法修正案（七）.md
│   └── 行政法/
│       └── 个人信息保护法（2021-08-20）.md
├── samples/           # 示例 SFT 数据
│   └── sample_sft.json
├── eval/              # 评测数据集
│   └── eval_dataset.json
├── raw/               # 原始数据（不入库，需自行下载）
├── processed/         # 处理后数据（不入库，由脚本生成）
└── faiss_index/       # FAISS 索引（不入库，由脚本生成）
```

## 法律文档格式

法律文档使用 Markdown 格式，结构如下：

```markdown
# 中华人民共和国个人信息保护法

2021年8月20日 第十三届全国人民代表大会常务委员会第三十次会议通过

## 第一章 总则

第一条 为了保护个人信息权益，规范个人信息处理活动，促进个人信息合理利用，根据宪法，制定本法。

第二条 自然人的个人信息受法律保护，任何组织、个人不得侵害自然人的个人信息权益。
```

系统会自动提取：
- 法律名称（第一个 `#` 标题）
- 生效日期（头部文本中的日期）
- 章节结构（`##` → 章，`###` → 节）
- 法条编号（`第X条`）

## 获取原始数据

原始数据集较大，不入 Git 仓库。请按 [docs/dataset.md](../docs/dataset.md) 中的说明下载并放入 `raw/` 目录。

## 添加新法律

1. 将 Markdown 格式的法律文档放入 `laws/` 对应分类目录
2. 重新构建索引：`python scripts/build_index.py --law-dir data/laws`
